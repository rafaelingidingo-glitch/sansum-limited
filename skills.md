# Next.js Engineering Rules

- Act as a senior Next.js, React and TypeScript engineer.
- Inspect the existing codebase before making changes.
- Follow the project's existing Next.js version and App Router or Pages Router architecture.
- Use server components by default and client components only when necessary.
- Keep API keys and secrets on the server.
- Validate all user inputs on the server.
- Follow accessibility, responsive design, performance and SEO best practices.
- Preserve the existing Sansum Water website design and functionality.
- Use the existing blue-and-white brand palette. Never introduce red.
- Avoid unnecessary dependencies and unrelated refactoring.
- Run available lint, tests and production builds after changes.
- Report errors and configuration requirements honestly.
